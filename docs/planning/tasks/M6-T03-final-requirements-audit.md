# M6-T03 — Audit requirements and report delivery status

**Objective.** Produce an evidence-linked DONE/PARTIAL/NOT DONE assessment for every completion checklist item.

**Requirements references.** `requirements.md` §1.1, §17–18.

**Dependencies.** M6-T01, M6-T02, all prior milestones.

**Files/modules affected.** Final delivery report or `docs/planning/completion.md`; requirements evidence links.

**Implementation steps.** Map each product, integrity, reliability and quality checklist item to implementation and test/load evidence; identify unresolved product decisions and limitations; verify run instructions from clean setup.

**Acceptance criteria.** Every checklist item has status and path/evidence; no requirement is called done based only on an endpoint/table; test and load claims match recorded runs; remaining work is explicit.
